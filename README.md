# TakeAway Simulation
## Overview
This repository uses [O2DESpy](https://github.com/steveyeoks/o2despy) to simulate a simple food delivery scenario. The model includes a rider, a customer and 4 restaurants. 
## Statistical Indicators

| Indicators | Unit |
| ---------- | ---- |
| Busy rate of restaurant | % |
| Busy rate of rider | % |
| Average waiting time of orders | hours |

## Dashboard
The [dashboard](https://BianHaifan.github.io/TakeAway-Simulation/) shows a simulation result of the model, which the time of warming up is 72 hours and simulation time is 2 hours.
